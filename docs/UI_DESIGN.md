# VeyTerm UI

终端占据主要空间。界面沿用暖灰背景、鼠尾草绿强调色，使用留白和文字层级区分区域，常驻界面不加卡片、描边或分隔线。

## 会话与操作

- 顶部栏最小 56 dp，高度随字体增大。显示当前会话名称和 shell 标题；未命名会话在顶部和抽屉中统一显示 `Local shell N`。异常退出显示退出码和错误色。
- 点击菜单图标或会话标题打开 280 dp 会话抽屉。标题下显示实际会话数量，每行展示名称、shell 标题和状态。当前会话使用柔和底色，并向读屏软件提供当前状态。
- 每行右侧有独立的 48 dp 操作按钮，可重命名或关闭该行对应的会话。关闭运行中的 shell 需要在应用内确认；取消保留会话，已退出的会话直接移除。删除后台会话保留当前前台会话。
- 未命名会话的序号随列表重新排列；需要固定名称时使用重命名。
- 顶部 `+` 新建会话；长按 `+` 或选择菜单中的 `New named session` 可以先命名。原有 failsafe 入口保留。
- 顶部更多菜单提供快捷键栏、文本输入页、键盘、命名新会话、保持屏幕常亮和设置。抽屉中仍保留直接进入设置的按钮。
- 文本输入页至少 48 dp 高，独立于快捷键的行数。隐藏输入页时把焦点还给终端，保留尚未提交的输入。发送行为沿用终端原有逻辑。
- 抽屉使用 `start` 方向打开、关闭，使从右向左布局的行为一致。

## 颜色

终端的日间和夜间模式都使用同一套深色画布，状态栏使用浅色图标。颜色集中在 `values/colors.xml` 和 `values-night/colors.xml`，浮动菜单和关闭确认也使用相同色系。

| 用途 | 颜色 |
| --- | --- |
| 终端背景 | `#211F20` |
| 抽屉和快捷键栏 | `#2A2728` |
| 浮动菜单和按压反馈 | `#302C2C` |
| 当前会话 | `#3A3932` |
| 主文字 | `#E8E1D8` |
| 次要文字 | `#B8AEA3` |
| 强调色、运行状态 | `#ABB89B` |
| 异常退出 | `#C56B5F` |

## 预览与验证

[`preview/veyterm-preview.html`](preview/veyterm-preview.html) 展示单终端、会话抽屉和实际已实现的操作布局，支持新建、切换、重命名、关闭和输入页切换。它是界面预览，不执行命令；设置和保持屏幕常亮仅在 Android 应用中可用。预览不展示尚未实现的分屏。

本地构建和测试：

```sh
./gradlew :app:assembleDebug testDebugUnitTest -PveytermDebugAbi=x86_64
```

交互验收检查会话的选择与命名、取消关闭、删除后台会话、非零退出状态、输入页焦点与高度、横竖屏和放大字体。浏览器预览不能替代 Android 验收。

2026-10-29 本地验收：187 项单元测试通过；API 33 x86_64 模拟器通过上述交互检查，以及 150% 字体下的横竖屏检查。文本输入页测得 48 dp，隐藏后焦点回到终端。390 × 844 和 1440 × 900 的浏览器预览通过新建、后台重命名、取消关闭、后台关闭、输入草稿与键盘焦点检查，无横向溢出。ARM64 debug APK 构建、内嵌 bootstrap 校验和 APK v1/v2 签名检查通过，尚未在 ARM 实体机执行；本轮未发布新 release。

本地证据保存在 `build/verification/session-polish-20261029/`，预览截图保存在 `output/playwright/veyterm-1029-*.png`。这些材料不提交到源码仓库。

布局必须保留 `TermuxActivityRootView` 的层级和底部 sentinel；这两个边界负责 Android 输入法和 Gboard 的安全区处理。`ai_context_panel` 默认隐藏，尚未接入真实 provider。
