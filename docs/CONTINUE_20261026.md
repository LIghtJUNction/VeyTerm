## Current changes

- Flattened terminal header, session drawer and command input; clearer typography,
  48 dp toolbar controls, and readable status-bar icons in the light system mode.
  The desktop/mobile HTML preview follows the same palette and spacing.
- Python `3.14.8-0.1` corrects a converted Debian hook that deleted pacman-owned
  pip. Package upgrade and reinstall preserve all 607 pip files. A regression
  test fails before the conversion fix and passes afterward.
- Existing bundled repository configuration advances to the current signed
  release while retaining the original mirror. Custom servers and symlinked
  configuration files are preserved. Older missing pip files can be restored
  with `pacman -Syu python-pip` after updating.
- Package manifests now describe the actual native Bionic environment and
  VeyTerm keyring. New Linux setup includes Python virtual-environment support.
